# Telegram 알림

## 사전 준비

- BotFather로 봇 생성 후 `TELEGRAM_BOT_TOKEN` 발급
- 알림 수신할 chat_id 확보 (`TELEGRAM_CHAT_ID`, 본인 개인 채팅 또는 전용 채널)
- 둘 다 `.env`에 보관, 저장소에 커밋 금지 (`.env.example`에는 키 이름만)

## 메시지 발송 조건

- `matches.is_eligible = true` AND `confidence >= 임계값` AND `notified_at IS NULL`
  인 레코드를 대상으로 발송
- 발송 성공 시 `notified_at` 갱신 (중복 발송 방지)

## 메시지 포맷 (예시)

```
🔔 [금융위원회] 새 공고가 당신의 조건에 맞습니다

제목: 2026년 청년 금융교육 지원사업 공고
게시일: 2026-09-30
판단 근거: 만 19~34세 청년 대상이며 소득분위 8분위 이하 조건 충족

원문 보기: https://www.fsc.go.kr/...
```

- 구성 요소: 기관명, 제목, 게시일, LLM 판단 근거(`reason`), 원문 링크
- 여러 건이 동시에 쌓인 경우: 1건당 1메시지 또는 다이제스트(여러 건을 하나로 묶어 발송) 중
  선택 가능하도록 설정값으로 분리 (1차 구현은 1건당 1메시지로 단순하게 시작)

## 발송 실패 처리

- Telegram API 실패(네트워크 오류, rate limit 등) 시 재시도 1~2회
- 재시도 후에도 실패하면 `notified_at`을 갱신하지 않고 다음 배치에서 재발송 시도
- 과도한 재시도로 인한 동일 메시지 중복 발송 방지를 위해 재시도 간 지수 백오프 적용

## 향후 확장 고려 (1차 범위 아님)

- 다중 사용자 지원 시 `user_profiles`에 `telegram_chat_id` 컬럼 추가해 프로필별 발송 대상 분리
- "관심 없음" 피드백을 Telegram에서 받아 LLM 판별 임계값 조정에 활용하는 피드백 루프
